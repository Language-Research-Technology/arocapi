arocapi has no Express adapter, but you don't need to switch frameworks. Register the plugin on a Fastify instance as
in [Your first API](/getting-started/first-api/), and have Express forward requests to it instead of calling
`fastify.listen()`.

```sh
pnpm add express
pnpm add -D @types/express
```

<Code code={expressIndex} lang="ts" title="src/index.ts" />

Express strips the `/api` mount path before forwarding, so the entity list is at `/api/entities`.

Mount arocapi before any middleware that reads the request body, such as `express.json()`. Fastify parses the body
itself, and if Express has already consumed it, `POST /search` never gets a response.

CORS, error responses and unknown paths are set on the Fastify instance, as described in [HTTP](/configuration/http/).
