With the database and index ready, you can register the plugin. This page builds a public repository that stores its
RO-Crate metadata and files on local disk, then shows how to require a login for some of it.

## Register the plugin

arocapi needs seven options:

- `prisma` and `opensearch`: the clients for your database and search index
  ([Data sources](/configuration/data-sources/)).
- `entityVisibilityFilter` and `searchVisibilityFilter`: which entities exist for a request, as a Prisma condition and
  an OpenSearch query. Hidden entities never appear in any response ([Visibility](/configuration/visibility/)).
- `access`: whether a request may read a visible entity's full RO-Crate metadata and, for a file, its content
  ([Access](/configuration/access/)).
- `fileHandler` and `roCrateHandler`: how to fetch a file's content and an entity's RO-Crate metadata from your
  storage ([Handlers](/configuration/handlers/)).

Every one of these functions gets the request context, `{ request, fastify }`, so its answer can depend on who is
asking. This first API answers the same for everyone: every entity is visible and every entity is accessible.
[Visibility vs Access](/concepts/visibility-vs-access/) explains how the two differ.

```ts twoslash title="src/index.ts"
// @allowImportingTsExtensions
// @noEmit
// @filename: src/generated/prisma/client.ts
export declare const PrismaClient: new (options: {
  adapter: import('@prisma/adapter-mariadb').PrismaMariaDb;
}) => import('arocapi').Options['prisma'];
// @filename: src/index.ts
// ---cut---
import { createReadStream } from 'node:fs';
import { stat } from 'node:fs/promises';
import { Client } from '@opensearch-project/opensearch';
import { PrismaMariaDb } from '@prisma/adapter-mariadb';
import arocapi, {
  AllPublicAccess,
  AllVisibleEntityFilter,
  AllVisibleSearchFilter,
  type FileHandler,
  type RoCrateHandler,
} from 'arocapi';
import Fastify from 'fastify';
import { PrismaClient } from './generated/prisma/client.ts';

const prisma = new PrismaClient({
  adapter: new PrismaMariaDb(process.env.DATABASE_URL as string),
});
const opensearch = new Client({ node: process.env.OPENSEARCH_URL });

// Where each entity's RO-Crate and each file is stored, kept in their meta column
type StoredMeta = { storagePath: string };

const fileHandler: FileHandler = {
  head: async (file) => ({
    contentType: file.mediaType,
    contentLength: Number(file.size),
  }),
  get: async (file) => {
    const { storagePath } = file.meta as StoredMeta;

    return {
      type: 'file',
      path: storagePath,
      metadata: { contentType: file.mediaType, contentLength: Number(file.size) },
    };
  },
};

const roCrateHandler: RoCrateHandler = {
  head: async (entity) => {
    const { storagePath } = entity.meta as StoredMeta;
    const { size, mtime } = await stat(storagePath);

    return { contentType: 'application/ld+json', contentLength: size, lastModified: mtime };
  },
  get: async (entity) => {
    const { storagePath } = entity.meta as StoredMeta;
    const { size, mtime } = await stat(storagePath);

    return {
      type: 'stream',
      stream: createReadStream(storagePath),
      metadata: { contentType: 'application/ld+json', contentLength: size, lastModified: mtime },
    };
  },
};

const fastify = Fastify({ logger: true });

await fastify.register(arocapi, {
  prisma,
  opensearch,
  entityVisibilityFilter: AllVisibleEntityFilter,
  searchVisibilityFilter: AllVisibleSearchFilter,
  access: AllPublicAccess,
  fileHandler,
  roCrateHandler,
});

await fastify.listen({ port: 3000 });
```

The handlers only run after visibility and access have passed, so they never need to check either. Returning `false`
from a handler gives a 404. [Storage strategies](/strategies/storage/) covers other ways to serve content, such as
redirecting to object storage.

## Add an entity

arocapi serves what is in your database and index; it doesn't write to them. In a real repository your indexer fills
both from your RO-Crates. For now, add a collection with one file by hand. Create its RO-Crate metadata and the file:

```sh
mkdir data
echo 'Hello from arocapi' > data/hello.txt
cat > data/ro-crate-metadata.json <<'EOF'
{
  "@context": "https://w3id.org/ro/crate/1.1/context",
  "@graph": [
    { "@id": "ro-crate-metadata.json", "@type": "CreativeWork", "about": { "@id": "./" } },
    { "@id": "./", "@type": "Dataset", "name": "My first collection", "hasPart": [{ "@id": "hello.txt" }] },
    { "@id": "hello.txt", "@type": "File", "name": "hello.txt", "encodingFormat": "text/plain" }
  ]
}
EOF
```

Then a script that records both entities in the database and the index:

```ts twoslash title="scripts/seed.ts"
// @allowImportingTsExtensions
// @noEmit
// @filename: src/generated/prisma/client.ts
export declare const PrismaClient: new (options: {
  adapter: import('@prisma/adapter-mariadb').PrismaMariaDb;
}) => import('arocapi').Options['prisma'];
// @filename: scripts/seed.ts
// ---cut---
import { resolve } from 'node:path';
import { Client } from '@opensearch-project/opensearch';
import { PrismaMariaDb } from '@prisma/adapter-mariadb';
import { PrismaClient } from '../src/generated/prisma/client.ts';

const prisma = new PrismaClient({
  adapter: new PrismaMariaDb(process.env.DATABASE_URL as string),
});
const opensearch = new Client({ node: process.env.OPENSEARCH_URL });

const licence = 'https://creativecommons.org/licenses/by/4.0/';
const collectionId = 'https://example.org/collection';
const fileId = 'https://example.org/collection/hello.txt';

const entities = [
  {
    id: collectionId,
    name: 'My first collection',
    description: 'A collection with one file',
    entityType: 'http://pcdm.org/models#Collection',
    memberOf: null,
    rootCollection: null,
    metadataLicenseId: licence,
    contentLicenseId: licence,
  },
  {
    id: fileId,
    name: 'hello.txt',
    description: 'A greeting',
    entityType: 'http://schema.org/MediaObject',
    memberOf: collectionId,
    rootCollection: collectionId,
    metadataLicenseId: licence,
    contentLicenseId: licence,
  },
];

await prisma.entity.create({
  data: { ...entities[0], meta: { storagePath: resolve('data/ro-crate-metadata.json') } },
});
await prisma.entity.create({ data: entities[1] });
await prisma.file.create({
  data: {
    id: fileId,
    filename: 'hello.txt',
    mediaType: 'text/plain',
    size: 19,
    meta: { storagePath: resolve('data/hello.txt') },
  },
});

await opensearch.bulk({
  body: entities.flatMap((entity) => [{ index: { _index: 'entities', _id: entity.id } }, entity]),
  refresh: true,
});

await prisma.$disconnect();
```

A file is two rows: an `Entity` that gives it its place in the collection and its licences, and a `File` with the same
ID that describes the bytes.

```sh
node --env-file=.env scripts/seed.ts
```

## Call the API

Start the server:

```sh
node --env-file=.env src/index.ts
```

Entity IDs are URLs, so encode them in paths. [Routes](/reference/routes/) lists every route and its parameters.

```sh
curl http://localhost:3000/entities
curl http://localhost:3000/entity/https%3A%2F%2Fexample.org%2Fcollection
curl http://localhost:3000/entity/https%3A%2F%2Fexample.org%2Fcollection/metadata
curl http://localhost:3000/file/https%3A%2F%2Fexample.org%2Fcollection%2Fhello.txt
curl -X POST http://localhost:3000/search -H 'Content-Type: application/json' -d '{"query": "greeting"}'
```

Each entity in a response carries an `access` object saying whether this request may read its metadata and content:

```json
{
  "id": "https://example.org/collection",
  "name": "My first collection",
  "description": "A collection with one file",
  "entityType": "http://pcdm.org/models#Collection",
  "memberOf": null,
  "rootCollection": null,
  "metadataLicenseId": "https://creativecommons.org/licenses/by/4.0/",
  "contentLicenseId": "https://creativecommons.org/licenses/by/4.0/",
  "access": { "metadata": true, "content": true }
}
```

## Require a login for some content

Most repositories have content that only some people may read. Replace `AllPublicAccess` with an access function
that checks licences, and tell arocapi how to recognise a logged-in request with
[`isAuthenticated`](/configuration/access/#isauthenticated). How a request
proves who it is stays up to your app; this example accepts a single bearer token.

```ts twoslash title="src/index.ts"
import type { FastifyInstance } from 'fastify';
declare const fastify: FastifyInstance;
declare const prisma: import('arocapi').Options['prisma'];
declare const opensearch: import('arocapi').Options['opensearch'];
declare const fileHandler: import('arocapi').FileHandler;
declare const roCrateHandler: import('arocapi').RoCrateHandler;
// ---cut---
import arocapi, {
  AllVisibleEntityFilter,
  AllVisibleSearchFilter,
  type IsAuthenticated,
  LicenceAccess,
} from 'arocapi';

const openLicences = new Set(['https://creativecommons.org/licenses/by/4.0/']);

const isAuthenticated: IsAuthenticated = ({ request }) =>
  request.headers.authorization === `Bearer ${process.env.API_TOKEN}`;

const access = LicenceAccess({
  hasLicence: async (licenceId, context) => openLicences.has(licenceId) || (await isAuthenticated(context)),
  authorisationUrl: (licenceId) => `https://example.org/request-access?licence=${encodeURIComponent(licenceId)}`,
});

await fastify.register(arocapi, {
  prisma,
  opensearch,
  entityVisibilityFilter: AllVisibleEntityFilter,
  searchVisibilityFilter: AllVisibleSearchFilter,
  access,
  isAuthenticated,
  fileHandler,
  roCrateHandler,
});
```

Now an entity whose content licence isn't open is still listed, with `access.content` set to `false` and a
`contentAuthorizationUrl` saying where to ask for it. Fetching its file without the token gets a 401, so a client knows
to prompt for a login. With the token it gets the file. In a repository where logged-in users hold different
licences, a logged-in request without the licence gets a 403.

Visibility filters work the same way: they receive the request context, so an entity can be hidden from some requests
and not others. [Visibility vs Access](/concepts/visibility-vs-access/) follows a worked example through every route,
and [Transformers](/configuration/transformers/) shows how to add your own fields to responses.
